# Attachment display classnames

[Home](Home.md) · [Display behavior](Attachment-Visibility.md)

These are the built-in class rules generated by the documented main settings. Use them for `AttachmentDisplay[].ItemClassname`. They are placed-item settings classes, not a complete spawn/kit catalogue. A rule on an object without visible normal attachments may have no visible effect.

Colored single lockers share `VBI_Locker`; colored triple lockers share `VBI_TripleLocker`. Their color-specific spawn classnames do not select independent visibility rules in this implementation.
