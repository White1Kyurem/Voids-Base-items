# Reference scope

[Home](Home.md)

This guide documents **main settings schema 2** and **air-conditioner settings schema 1** using the supplied VBI configuration loaders and the code that consumes their values. A schema marker is not a Workshop release version.

The repository currently provides documentation and examples. It does not contain the mod’s private model/script source or a replacement Workshop download.

## How to use this reference with another build

Keep any additional fields generated by your installed release. If a newer release renames a field, changes a limit or connects a previously unused field, its generated configuration and matching implementation take precedence. Report differences so the documentation can be updated.

The reference explicitly distinguishes loaded fields from their effects. In the supplied implementation:

- `TrashConfirmSeconds` is loaded but not used by the empty-bin action.
- `WallLampEnergyPerSecond` and `FloorLampEnergyPerSecond` apply to their named classes, not every light.
- Colored lockers share base attachment-display settings.
- No manual CodeLock priority, wall-placement tolerance, inventory-size or seating-offset field exists in the documented JSON schema.

Adding an undocumented key does not create that functionality. Inventory dimensions, slots, model/proxy transforms, placement rules and seating alignment are defined by the mod rather than the settings listed here.

The examples and cross-links were checked against the referenced settings. Publishing this guide does not represent a new in-game test of every server combination.
